# Verification

This suite executes the shipped HTML in a Node VM with a simulated DOM and native Canvas. It is not a browser, layout engine, touchscreen, real SDK test or FPS benchmark.

The scripts currently resolve `underroot/` from the working directory for reproducibility. To run from any checkout name, use:

```sh
node tests/run.cjs
```

Install `@napi-rs/canvas` as a development dependency if it is unavailable. In Codex the harness resolves it through `CODEX_PRIMARY_RUNTIME_NODE_MODULES`. Python 3 is required for building and packaging; the game itself requires no installed packages.

`core-results.json`, `platform-results.json` and `extended-results.json` contain the executed checks. PNG files generated by the harness are Canvas render inspections only, without browser UI layout.
